DevOps Curriculum

Progress from application development to production-grade operations.

01
FOUNDATIONS

DevOps Fundamentals & Linux

Understand how software moves from development to production.

  • DevOps culture, SDLC, Agile and Scrum
  • Linux commands, permissions, processes and services
  • Shell scripting and troubleshooting
  • Networking, DNS, HTTP, SSH and TLS
LinuxBashNetworking

SOURCE CONTROL

Git & GitHub

Collaborate safely and maintain traceable application changes.

  • Repositories, commits, branches and merges
  • Pull requests, code reviews and conflict resolution
  • GitHub issues, tags and release management
  • Branching strategies and team workflows
GitGitHubCode Review

APPLICATION DEVELOPMENT

Build a Three-Tier Application

Understand the application before automating its delivery.

  • Frontend fundamentals: HTML, CSS and JavaScript
  • Node.js and Express REST APIs
  • PostgreSQL, SQL and database initialization
  • Environment variables and application configuration
FrontendNode.jsPostgreSQL
04
CONTAINERIZATION

Docker & Docker Compose

Package and run consistent, reproducible application environments.

  • Images, containers, volumes and networks
  • Dockerfiles, layers and multi-stage builds
  • Docker Compose for multi-tier applications
  • Container logs, health checks and troubleshooting
DockerComposeContainers
05
CI/CD AUTOMATION

Jenkins & GitHub Actions

Automate code validation, image publishing and deployments.

  • Pipeline stages, jobs, runners and agents
  • Build, test, artifact and deployment workflows
  • Secrets, credentials and environment protection
  • Automated releases, rollback and approvals
JenkinsGitHub ActionsCI/CD
06
SECURITY & QUALITY

DevSecOps

Integrate security checks into the software delivery lifecycle.

  • Static code analysis with SonarQube
  • Container vulnerability scanning with Trivy
  • Dependency scanning and image security
  • Secrets management and least privilege
SonarQubeTrivySecurity
07
CLOUD & INFRASTRUCTURE

AWS & Infrastructure as Code

Provision secure cloud infrastructure and understand deployment targets.

  • EC2, IAM, VPC, security groups and ECR
  • Networking, storage and load balancing
  • Terraform fundamentals and state management
  • Infrastructure configuration and cost awareness
AWSECRTerraform

ORCHESTRATION

Kubernetes

Deploy and operate resilient containerized workloads.

  • Pods, Deployments, Services and Namespaces
  • ConfigMaps, Secrets, Ingress and persistent storage
  • Requests, limits, probes and autoscaling
  • Local clusters using kind and kubectl troubleshooting
Kuberneteskubectlkind

PACKAGING & GITOPS

Helm & Argo CD

Manage application releases declaratively with versioned configuration.

  • Helm charts, templates and values files
  • Application environments and configuration overrides
  • GitOps reconciliation with Argo CD
  • Sync, drift detection and rollback
HelmArgo CDGitOps

OBSERVABILITY

Monitoring, Metrics & Logs

Understand application health and diagnose production issues.

  • OpenTelemetry and distributed tracing basics
PrometheusGrafanaLoki

Make secure, repeatable delivery easier for application teams.

Hands-on Labs

Practice real-world tasks. Mark each lab complete as you finish it.

🐧

Lab 01 — Linux & Git

Create a repository, work with branches, resolve a merge conflict and automate a server check with Bash.

🐳

Lab 02 — Dockerize the App

Containerize the frontend and Express API. Connect the services to PostgreSQL with Compose.

🔄

Lab 03 — CI/CD Pipeline

Build and test the application, scan images, publish versioned artifacts and deploy to EC2.

🛡️

Lab 04 — DevSecOps

Add static analysis, vulnerability scanning, secure secrets and least-privilege access.

☸️

Lab 05 — Kubernetes

Deploy the application to kind. Configure Services, Ingress, health probes and resource limits.

🚀

Lab 06 — GitOps

Package the app with Helm and configure Argo CD to reconcile changes from Git.

📈

Lab 07 — Observability

Build a Grafana dashboard, collect metrics and logs, and configure an actionable alert.

🧰

Lab 08 — Platform Engineering

Create a reusable application template and document a developer self-service workflow.
